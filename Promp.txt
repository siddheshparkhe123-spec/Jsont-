System Design Document (SDD)

Project: EXIM WDM Automation via NAS (Azure Hosted)

⸻

1. Overview

This solution automates the processing of Excel files received on a NAS drive. A scheduled Azure-based job reads the file daily, processes each work item by invoking the WDM API using IB2B authentication, and writes back the response into the same Excel file.

⸻

2. Objective

* Eliminate manual creation of work items
* Reduce processing time drastically
* Enable scalable and reliable batch processing
* Ensure secure API integration via IB2B
* Maintain audit trail via logs

⸻

4. Component Description

4.1 NAS Drive

* Stores input Excel file
* Same file updated with response
* Access via secure credentials

⸻

4.2 Azure Scheduler

* Implemented using:
    * Azure Function Timer Trigger (preferred)
* Runs daily at 3:30 AM IST

⸻

4.3 Processing Service

* Hosted on Azure Function App / App Service
* Responsibilities:
    * Read Excel from NAS
    * Parse work items
    * Invoke API per row
    * Update Excel

⸻

4.4 IB2B Authentication

* Secure authentication layer
* Token/header-based authentication
* Token handled dynamically

⸻

4.5 WDM API

* External system API
* Called for each work item
* Returns processing status

⸻

4.6 Response Handler

* Maps API response to Excel columns
* Handles success/failure scenarios

⸻

4.7 Output Writer

* Writes:
    * Status
    * Response message
    * Timestamp
* Saves updated file to NAS

⸻

5. Data Flow

1. Excel file is placed in NAS
2. Azure scheduler triggers at 3:30 AM IST
3. Processing service reads file
4. Iterates through each row
5. For each work item:
    * Authenticate via IB2B
    * Call WDM API
    * Receive response
6. Update Excel
7. Save file back to NAS

⸻

6. Error Handling

* Retry mechanism for API failures (configurable)
* Log error per record
* Continue execution for remaining records
* Mark failed records in Excel

⸻

7. Logging & Monitoring

* Tools:
    * Azure Application Insights
    * Azure Monitor
* Logs captured:
    * Execution status
    * API request/response (masked)
    * Errors and exceptions
* Alerting enabled for failures

⸻

8. Security

* Secrets stored in Azure Key Vault
* Secure NAS access
* HTTPS API calls
* Sensitive data masked in logs
* RBAC for Azure resources

⸻

9. Performance Considerations

* Sequential processing (default)
* Can be enhanced with controlled parallel processing
* API timeout and retry configured
* Handles large file volumes efficiently

⸻

10. Assumptions

* Excel format remains consistent
* NAS accessible at runtime
* WDM API available
* IB2B credentials valid

⸻

11. Dependencies

* NAS access
* WDM API
* IB2B authentication service
* Azure infrastructure

⸻

12. Deployment Architecture

* Code hosted on Azure (GitHub/Azure DevOps)
* CI/CD pipeline for deployment
* Deployment target:
    * Azure Function App
* Environments:
    * Dev / UAT / Prod

⸻

13. Execution Flow

1. Scheduler triggers job
2. Azure Function starts
3. Connects to NAS
4. Reads Excel
5. Processes each work item
6. Calls WDM API
7. Updates Excel
8. Saves output
9. Logs execution

⸻

14. Scalability

* Supports increase beyond 400 work items/day
* Can scale via:
    * Azure Function scaling
    * Parallel processing (if API allows)

⸻

15. Future Enhancements

* Dashboard for monitoring
* Retry queue mechanism
* Email notification on completion
* Event-driven architecture

⸻

16. Business Impact & Performance Metrics

16.1 Efficiency Improvement

* Manual: 5–8 minutes per work item
* Automated: ~3 seconds per work item

⸻

16.2 Volume Handling

* Current: ~400 work items/day
* Scalable for future growth

⸻

16.3 Time Savings Analysis

Metric	Manual	Automated
Time per item	5–8 mins	~3 sec
Time for 400 items	~33–53 hours	~20 minutes

👉 ~99% reduction in processing time

⸻

16.4 FTE Savings

* Estimated savings: ~3 FTE
* Reduced manual workload
* Lower operational cost

⸻

16.5 Turnaround Time (TAT)

* Earlier: Hours to days
* Now: ~20 minutes for full batch

⸻

16.6 Business Value

* Faster processing
* Improved accuracy
* Reduced errors
* Better customer experience
* Enables focus on higher-value tasks

⸻

17. Key Architecture Decisions

* Azure Function for cost-efficient execution
* Key Vault for secure secret management
* NAS retained as source system
* Controlled processing based on API limits
